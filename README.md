# Eco Journey

## Overview

Eco Journey is an interactive website developed as part of the **COM109 Web Development** group coursework at **Ulster University**. The website aims to encourage users to adopt environmentally friendly habits through interactive eco challenges, educational content, a carbon footprint calculator, an eco quiz, and progress tracking. The project demonstrates the use of modern web development techniques, responsive design, and JavaScript to create an engaging user experience.

---

## Features

* Responsive multi-page website
* Home page introducing Eco Journey
* Daily Eco Fact section
* Eco Challenges with filtering and favourites
* Learn page with sustainability information
* Carbon Footprint Calculator
* Interactive Eco Quiz
* Progress Tracker using Local Storage
* Contact form with validation
* Dark Mode
* Responsive design for desktop, tablet, and mobile devices

## How to Run

1. Clone or download this repository.
2. Open the project folder in **Visual Studio Code**.
3. Install the **Live Server** extension (if it is not already installed).
4. Right-click on `index.html` and select **Open with Live Server**.
5. Explore the website through the navigation menu.
